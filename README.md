# 簡報黑板播放台 Lecture Blackboard

雙螢幕簡報系統。上傳簡報後，一個視窗當「控制台」、一個當「投影畫面」，
播放中按右下角的筆即可隨手打字投到大螢幕，下方自動配上英文翻譯；
簡報裡的影片也能掛到對應頁、在大螢幕全螢幕播放。

**線上使用**：https://joshlinmoments.github.io/lecture-blackboard/

## 怎麼用（同一台電腦接投影機）
1. 用上面的網址開**兩個**瀏覽器視窗。
2. 一個選「**控制台**」留在筆電；另一個選「**投影畫面**」拖到投影機、按全螢幕。
3. 在控制台**上傳簡報**（PDF 或圖片）。有影片的那幾頁按「🎬 這頁加影片」掛上影片檔。
4. 要補充說明：按右下角的**筆**，打中文即時投到大螢幕，下方自動配英文（可手改）。

## 特色
- 雙螢幕即時同步，走瀏覽器內建 BroadcastChannel + IndexedDB，**免網路、免後端**。
- 靜態投影片用 **PDF**（pdf.js，保真度最高）或 **PNG/JPG**。
- **影片掛頁**：影片只在投影端解碼播放，控制台當遙控（播放/暫停/進度）。
  首次請先點一下投影畫面以解鎖聲音（瀏覽器自動播放政策）。
- **英文自動翻譯**：於 claude.ai Artifact 環境用 Claude 翻譯；在本站則用 MyMemory 網頁翻譯 API，皆可手動修改。
- 快捷鍵：`←/→` 翻頁、`B` 黑幕、`W` 白幕、`P` 黑板。

## 隱私
所有簡報與影片只存在你瀏覽器本機（IndexedDB），不會上傳到任何伺服器。
使用自動翻譯時，僅「黑板輸入的文字」會送往翻譯服務。
